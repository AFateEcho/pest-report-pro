# History 详情弹窗 - 设计文档

**日期：** 2026-06-05
**功能范围：** 在历史记录列表增加"点击查看详情"弹窗，支持轻量编辑
**核心约束：** 只做增量添加，不改动现有功能

---

## 1. 功能概述

用户在历史记录页面点击某一条记录，弹出详情窗口查看完整信息，并可以修改最常用的几个字段（客户信息、日期、备注等），不用离开当前页面。

**方案：** 轻量编辑（方案 A）—— 只开放最常改的字段，复杂的列表（化学品、报价项目）保持只读。

---

## 2. UI 设计（高级版）

### 2.1 视觉风格升级

在现有设计基础上做高级感提升，但不推翻已有样式：

- **弹窗背景：** 半透明黑色 `bg-black/40` + 毛玻璃模糊效果 `backdrop-blur-sm`
- **弹窗主体：** 白色卡片，`圆角 2xl`，`超大阴影 shadow-2xl`，`细灰边框`
- **顶部类型标签：** 带颜色的胶囊标签——
  - Report（服务报告）→ 蓝色 `bg-blue-50 text-blue-700`
  - Quote（报价单）→ 绿色 `bg-green-50 text-green-700`
  - Invoice（发票）→ 紫色 `bg-purple-50 text-purple-700`
- **分区标题：** 小字大写灰色字母，`text-xs font-semibold text-gray-400`，带底部细线分隔
- **只读字段：** 用浅灰色背景 `bg-gray-50` 包裹，视觉上看起来是"已设定"的状态，和可编辑的输入框形成对比
- **可编辑字段：** 沿用现有的 `.input-field` 样式，保持全 App 统一
- **动画：** 弹窗淡入（200ms）+ 轻微上滑效果 `translateY(10px)→0`

### 2.3 三种类型的字段权限对照

| 类型 | ✅ 可编辑字段 | 🔒 只读字段 |
|---|---|---|
| **服务报告 (Report)** | 客户姓名、电话、地址、服务日期、备注、建议 | 服务类型、技术员、化学品列表、签名 |
| **报价单 (Quote)** | 客户姓名、电话、地址、报价日期、备注 | 项目列表、小计、税费、总计 |
| **发票 (Invoice)** | 客户姓名、电话、地址、发票日期、到期日、**付款状态**、备注 | 项目列表、小计、税费、总计 |

- **付款状态**（仅 Invoice）：下拉选择 `已付(paid)` / `未付(unpaid)`，沿用现有的绿色/红色标签配色

## 3. 数据交互流程

1. **打开：** 用户点击历史记录卡片的**左侧信息区**（下载/删除按钮以外的区域）
2. **加载：** `showHistoryDetail(id)` 根据当前 `App.historyTab` 从 Storage 读取对应数据
3. **渲染：** 构建弹窗 DOM，可编辑字段用 `input/textarea/select`，只读字段用 `div` 展示
4. **编辑：** 用户修改字段
5. **保存：** `saveHistoryDetail(id)` 验证后调用 `Storage.updateReport/Quote/Invoice()`，然后：
   - 刷新历史列表 (`App.renderHistory()`)
   - 刷新 Dashboard (`App.renderDashboard()`)
   - 显示提示 "更改已保存"
   - 关闭弹窗
6. **取消/点击背景：** 关闭弹窗。如果有未保存的修改，弹出确认框 "是否放弃更改？"

## 5. 边界情况与安全防护

- **找不到记录：** 如果 Storage 里找不到该 id，关闭弹窗并提示 "记录不存在"
- **空保存：** 如果用户点了保存但什么都没改，直接关闭弹窗，不调用 Storage（避免无意义的写入）
- **电话格式化：** 弹窗里的电话输入框复用现有的 `App.formatPhoneInput()` 自动格式化
- **XSS 防护：** 弹窗里展示的用户输入内容必须经过 `escapeHtml()`（现有工具函数）
- **响应式：** 弹窗内容如果超出屏幕高度，内部可滚动 (`max-h-[90vh] overflow-y-auto`)
